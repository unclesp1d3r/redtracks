# Product

RedTracks is an offline, single-user desktop app for tracking engagements during penetration tests, OffSec labs/exams (OSCP, OSAI), and CTFs. It records hosts, services, per-service checklists, credentials, users, shares, loot, findings, and flags — and surfaces "what's left to try" on each target.

## Core principles

- **Offline and local only.** No network calls, no sync, no cloud, no multi-user. The operator is the only user of the machine.
- **The files are the interface.** All state is plain JSON (plus `notes.md`) under `~/RedTracks/engagements/`, readable and hand-editable in an editor if the app breaks. The app must keep faith with external edits (atomic writes, hash-check-and-reapply, mtime polling, conflict detection on notes).
- **Structure as data over free-form notes.** The value is knowing which ports have untouched checklists, which credentials were never tried on a host, which flags are missing, and how a host is reached.
- **Target-controlled strings are hostile.** Hostnames, domains, and OS strings from scan output are validated before becoming file paths, shell command substitutions, or Mermaid graph labels.

## Key features

- Import scan output from common tools (nmap/rustscan XML, masscan, ffuf, feroxbuster, gobuster, nikto, nuclei, enum4linux-ng, netexec) with a new/fills/duplicate preview before anything is written.
- Per-host progress summaries and a board sorted by owed proof (missing flags and slots) first, then by least checklist progress.
- An autogenerated Mermaid attack graph of hosts and access paths.
- Evidence capture: drop or paste screenshots and text onto a host or a specific target, file inbox screenshots to a host, import a session log and clip ranges from it, with required-proof slots from the checklist files so "did I capture everything" has an answer.
- Nine screens: Engagements, Board, Host, Tables, Import, What's left, Evidence, Inbox, Session logs — plus a command palette (cmd+k).

## Scope boundaries

**Never in scope** (against the product's identity): automated exploitation or scanning from inside the app, and any networked behavior.

**Deferred, not a focus of the MVP** (may come in later slices): report generation and a cross-engagement knowledge base.
